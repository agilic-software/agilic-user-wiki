# Feature Index

*Version v23 • August 30, 2026 • Section 0*

"I want to know about this feature — what is it for, how does it work?" Start here. Grouped by category rather than alphabetically, since most people arrive already knowing roughly what area they're curious about.

> **Note:** This expands on the [Terminology Index & Dictionary](/section-0-core-terminology/terminology-index-dictionary.md) (Section 0), which stays the authoritative single-term glossary. This index groups related terms into feature areas and points to the primary how-to document for each. Reporting rows point to Section 15 (Reporting Detail), the canonical source as of August 29, 2026 — Section 6/7/8 documents are thin pass-throughs to Section 15.
